## Use Time-Ordered UUIDs for Entities Created Offline

Офлайн-точка создаёт чеки, движения, документы и записи аудита в своей локальной БД и затем
синхронизирует их в облако. Последовательности (`identity`/`serial`) на разных точках выдают
одинаковые числа — при синхронизации конфликт или, хуже, перезапись. Поэтому идентификаторы
таких сущностей — UUID, генерируемые там, где сущность создаётся.

**Incorrect:**

```sql
-- Store A and store B both create receipt id = 1017 offline
create table receipts (
  id bigint generated always as identity primary key
);

-- Random UUIDv4 as PK on a 50M-row table: scattered inserts, index bloat
create table stock_movements (
  id uuid default gen_random_uuid() primary key  -- docs-check: ok (Incorrect example)
);
```

**Correct:**

```sql
-- Time-ordered UUIDv7, generated by the application — newId() in apps/api/src/core/database/ids.ts
-- (package uuid, v7) — identical on the cloud and offline stores. NO default in the database:
-- PostgreSQL 17 has no uuidv7(), and the catalog test asserts that no `id` column has a default.
create table receipts (
  tenant_id uuid not null references tenants (id),
  id uuid not null,             -- app-generated UUIDv7
  -- ...
  primary key (tenant_id, id)   -- tenant-class tables: the PK leads with tenant_id
);
```

Guidelines:

- Сущности, которые могут появиться на офлайн-точке или в браузерном буфере кассы (чек, оплата,
  движение, документ, аудит, операция очереди синхронизации) — UUIDv7 из приложения.
- Таблицы классов `platform`, `shared`, `system` — ключ `id` (тоже UUIDv7 из приложения);
  тенантные — `(tenant_id, id)` (модель данных). Исключение — локальные счётчики вроде
  `sync_outbox.store_seq` (`bigint identity`) — это порядок, не идентичность сущности.
- Человекочитаемые номера (номер чека в смене, номер документа) — отдельное поле, уникальное в
  пределах `(tenant_id, store_id, …)`, не первичный ключ.
- `serial` не используйте — `identity` стандартнее.

Генератор — пакет `uuid` (v7): в API — `newId()`, во фронтенде — тот же пакет (ADR-0015); без
самописных генераторов «похожих на UUID» строк.
