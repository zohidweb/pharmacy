## Use Time-Ordered UUIDs for Entities Created Offline

Офлайн-точка создаёт чеки, движения, документы и записи аудита в своей локальной БД и затем
синхронизирует их в облако. Последовательности (`identity`/`serial`) на разных точках выдают
одинаковые числа — при синхронизации конфликт или, хуже, перезапись. Поэтому идентификаторы
таких сущностей — UUID, генерируемые там, где сущность создаётся.

**Incorrect:**

```sql
-- Store A and store B both create receipt id = 1017 offline
create table receipts (
  id bigint generated always as identity primary key
);

-- Random UUIDv4 as PK on a 50M-row table: scattered inserts, index bloat
create table stock_movements (
  id uuid default gen_random_uuid() primary key
);
```

**Correct:**

```sql
-- Time-ordered UUIDv7, generated by the application (works identically on cloud and offline
-- stores); the DB default is only a fallback
create table stock_movements (
  id uuid primary key,          -- app-generated UUIDv7
  tenant_id uuid not null,
  -- ...
  unique (tenant_id, id)
);

-- PostgreSQL 18+ has a built-in uuidv7(); on older versions generate in the app.
-- Third-party extensions (e.g. pg_uuidv7) must also ship in the offline distribution image.
```

Guidelines:

- Сущности, которые могут появиться на офлайн-точке или в браузерном буфере кассы (чек, оплата,
  движение, документ, аудит, операция очереди синхронизации) — UUIDv7 из приложения.
- Чисто облачные справочники платформы (тарифы, служебные таблицы) — допустим
  `bigint generated always as identity`; не смешивайте стратегии внутри одного агрегата.
- Человекочитаемые номера (номер чека в смене, номер документа) — отдельное поле, уникальное в
  пределах `(tenant_id, store_id, …)`, не первичный ключ.
- `serial` не используйте — `identity` стандартнее.

Выбор функции/библиотеки генерации UUIDv7 в `libs/shared/util` согласуется при выборе слоя доступа
к данным (ADR), без самописных генераторов «похожих на UUID» строк.

Reference: [UUID Type](https://www.postgresql.org/docs/current/datatype-uuid.html),
[Identity Columns](https://www.postgresql.org/docs/current/sql-createtable.html#SQL-CREATETABLE-PARMS-GENERATED-IDENTITY)
