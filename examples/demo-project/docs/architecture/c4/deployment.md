# C4 — Deployment: Сервис уведомлений клиентов

| Контейнер | Среда | Контур сети | Примечание |
|---|---|---|---|
| Angular SPA | nginx (раздача статики) | Внутренний контур | Доступен только оператору банка из внутренней сети |
| API уведомлений | ВМ prod-кластера | Внутренний контур | .NET-приложение за внутренним балансировщиком |
| Воркер отправки | ВМ prod-кластера | Внутренний контур | Выход во внешнюю сеть (к СМС-шлюзу) только через DMZ-прокси |
| PostgreSQL | Кластер СУБД | Защищённый контур | Персональные данные; шифрование на уровне диска |
| Redis | Кластер СУБД | Защищённый контур | Очередь задач и кэш; персональных данных на диске не хранит |
| RabbitMQ | Кластер очередей | Защищённый контур | Очередь критичных уведомлений (отказ операции); исключение из радара, см. ADR-0003 |
| Выход к СМС-шлюзу | DMZ-прокси | DMZ | Единственная разрешённая точка выхода во внешнюю сеть для этого сервиса |

## Легенда

- **Внутренний контур** — сеть банка, недоступная извне; здесь работают API и воркер.
- **Защищённый контур** — выделенная сеть для хранилищ с персональными данными, доступ ограничен по ролям.
- **DMZ-прокси** — единственный разрешённый маршрут наружу, к внешнему провайдеру СМС; сам сервис к внешней сети напрямую не подключается.
- Разделение по контурам соответствует ограничению из stack.md, раздел «1. Профиль проекта»: персональные данные не покидают контур банка.
