# Changelog — ai-project-start

Формат версий: semver. Breaking-изменения процесса = мажорная версия.

## 0.2.2 — 2026-09-04 (находки ручного пилота, продолжение)

- **angular-dev расширен боевым скиллом angular-enterprise**: технические правила Angular
  (standalone, OnPush, inject(), @if/@for, signals, NgOptimizedImage) + три справочника
  references/ (component, forms-rxjs-signals, review); префикс селекторов нормализован.
- **/01 — этап «Репозитории кода»**: Claude предлагает схему репозиториев из профиля проекта
  (один деплой-юнит = один репозиторий; веб Full — отдельные -api/-web) и просит подтвердить.
- **/01 — мобильное приложение с готовым бэкендом**: явный вариант «бэкенд уже существует» —
  в интеграции и внешнюю систему C4, не в стек.

- **Мульти-репо как норма**: /01 спрашивает организацию кода (отдельные репозитории
  по компонентам — обычная практика — или монорепо), ответ — в stack.md «Репозитории кода»;
  /04 в мульти-репо режиме генерирует CLAUDE.md на каждый кодовый репозиторий
  (docs/architecture/generated/CLAUDE.<repo>.md) со ссылкой на репозиторий архитектуры,
  а корневой CLAUDE.md становится «архитектурным»; README и гайд-04 обновлены.

## 0.2.1 — 2026-09-04 (находки ручного пилота)

- **/01 — правило простого языка**: каждый вопрос интервью идёт с бытовым объяснением или
  тестом (критичность — «система лежит день: что произойдёт?»; расшифровка SLA/RTO/RPO/ПДн);
  подсказки в ячейках шаблона stack.md переписаны без жаргона; при затруднении Claude
  предлагает свой обоснованный вариант и просит подтвердить.
- **Аутентификация/IAM**: Keycloak (корпоративная аутентификация, SSO) — рекомендуемый
  вариант; самописная аутентификация допустима с обоснованием в ADR. Формулировки обновлены
  в скиллах стеков, шаблоне CLAUDE.md и demo-примере. Запрет самописной криптографии
  сохраняется.
- **БД**: PostgreSQL — рекомендуемая СУБД; другие СУБД — только с конкретным обоснованием
  в stack.md (почему PostgreSQL не подходит) и отдельным ADR.
- **/02 — экспорт диаграмм в PNG**: после создания .md Claude предлагает отрендерить каждую
  C4-диаграмму в docs/architecture/c4/img/*.png через mermaid-cli и установленный
  Chrome/Edge (без скачивания браузера); fallback — автоотображение в GitLab и mermaid.live.

## 0.2.0 — 2026-09-03

- **Усиление guard-хука**: нормализация путей (в т.ч. обратные слэши и `..`-переходы) перед
  проверками, fail-closed поведение при неразобранном вводе, покрытие `NotebookEdit`/`MultiEdit`.
- **Гейт ревью**: явно указано, кто проводит ревью архитектуры и как подать на ревью.
- **Согласование Lite**: ADR-0002 требуется только для Full-траектории.
- **Post-factum ревью** для Lite — с обязательным дедлайном фактического ревью.
- **Класс проекта** (Lite/Full) фиксируется в генерируемом `CLAUDE.md`.
- **Секции дня 1** в генерируемом `CLAUDE.md`: Git/MR-флоу, Definition of Done, ревью AI-кода,
  работа с секретами, interim CI/CD.
- **Типы проектов**: веб, мобильное, десктоп, API/интеграция — профильные вопросы интервью,
  мобильный security-чек-лист и store-deployment.
- **Desktop и push-сервисы** (FCM/APNs) — с правилом минимизации payload.
- **Монорепо vs несколько репозиториев** — раздел с рекомендацией и правилами оформления в
  ADR-0002.
- **6 скиллов стеков** (angular-dev, react-dev, dotnet-dev, php-dev, kotlin-dev, swift-dev),
  v1-черновики, с автоочисткой неиспользуемых после финализации.
- **README для новичков**: мини-словарь перед быстрым стартом, пояснения по hooks и
  slash-командам, уточнение формата APPROVAL.md, новые вопросы в ЧаВо.
