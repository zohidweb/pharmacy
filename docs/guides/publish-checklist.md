# Чек-лист публикации ai-project-start

1. Пилотный прогон авторами: скопировать шаблон во временную папку, пройти фиктивный
   проект от /01 до /04 — проверить порядок шагов, одобрение hooks, отказы (код до /01,
   /02 без stack.md, /04 без APPROVAL.md), повторный /04.
2. Создать центральный репозиторий в Git-системе банка (GitHub/GitLab/Gitea), включить
   режим template («Use this template»), права: команды — read, владелец радара — write.
3. Вписать URL репозитория в шапку tech-radar/RADAR.md (строка «Источник:») и закоммитить.
4. Залить содержимое папки ai-project-start/ как корень репозитория.
5. Пилот на реальной команде НИЗКОЙ зрелости, без участия авторов. Фиксировать все вопросы,
   на которые README не ответил → доработать README/гайды → версия 0.3.0.
6. Анонс в канале «Архитектура»: ссылка, с какого числа новые проекты стартуют только из
   шаблона, SLA ревью и исключений.
