# Демо-данные для QA

Синтетические данные: вымышленные названия с пометкой «Демо», производители «ДемоФарм», «Тестлаб» и подобные,
штрихкоды из внутреннего диапазона `200…` (не пересекаются с реальными товарами), ИНН `1000000xx`, телефоны
`+992 900 00 00 0x`. Реальных данных нет.

Загрузка — по разделу 4 [инструкции запуска](../01-zapusk-do-pervogo-cheka.md), строго по порядку: каталог,
поставщики, начальные остатки (остатки ищут товары каталога). Проверено загрузкой 2026-10-23: 28 товаров,
4 поставщика, черновик НО на 32 строки проводится без ошибок.

| Файл | Строк | Что внутри |
|---|---|---|
| `01-catalog.xlsx` | 28 | Товары всех стартовых категорий, формы из справочника, страна, наценка, минимальный остаток, предельная цена |
| `02-suppliers.xlsx` | 4 | Название, ИНН, телефон, адрес, отсрочка 0–45 дней |
| `03-opening-balances.xlsx` | 32 | Партии точки: серия, срок годности, количество, закупочная и розничная цены |

Столбцы совпадают с шаблонами, которые скачиваются в мастере загрузки («Скачать шаблон»).

## Товары для сценариев

| Сценарий | Товар | Штрихкод | Что проверить |
|---|---|---|---|
| Поштучная продажа, два штрихкода | Парацетамол-Демо (20 шт. в уп.) | `2000000000015`, `2009999000013` | Продажа штуки и упаковки; оба кода находят один товар |
| FEFO и короткий срок | Парацетамол-Демо, Витамин C Демо, Сироп от кашля Демо | `2000000000015`, `2000000000145`, `2000000000107` | Две партии; партия до 15.11.2026 продаётся первой и отмечается «истекает» |
| Срок «месяц.год» | Ибупрофен-Демо | `2000000000022` | Партия со сроком `06.2027` |
| Рецептурный | Амоксициллин-Демо, Эналаприл-Демо, Раствор для инъекций Демо | `2000000000039`, `2000000000084`, `2000000000138` | Предупреждение «по рецепту» на кассе |
| Предельная цена | Метформин-Демо (≤ 60,00, розница 42,00) | `2000000000077` | Цена выше предельной требует подтверждения |
| ПКУ | Трамадол-Демо (3 уп.) | `2000000000091` | Данные рецепта, право «Продажа ПКУ», журнал ПКУ |
| Нет цены | Магний B6 Демо, Зубная паста Демо | `2000000000169`, `2000000000213` | «Нет цены — касса не продаст»; цена задаётся в «Цены и скидки» |
| Товар без штрихкода | Травяной чай Демо (категория «Фиточаи») | — | Новая категория при загрузке; остаток найден по названию; продажа поиском |
| Дорогой товар | Глюкометр Демо (250,00) | `2000000000282` | Первый чек из инструкции |

Штрихкод товара — в каталоге (`01-catalog.xlsx`, столбец «Штрихкод») и в карточке товара.

Повторная загрузка каталога и поставщиков пропускает уже существующие записи. Повторная загрузка остатков создаст
второй черновик НО: мастер предупредит об этом, а проведение удвоит остатки.
