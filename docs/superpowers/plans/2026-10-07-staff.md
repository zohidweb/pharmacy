# Сотрудники, роли и терминалы — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** владелец собирает команду сети по настоящему API — сотрудники с паролем и PIN, одна роль и
охват точек, роли из каталога прав, терминалы точек — с запретом эскалации ADR-0018 и окном
«Подтвердите пароль» вместо повторного входа.

**Architecture:** `provision_tenant` создаёт четыре роли сети; новый тенантный модуль
`apps/api/src/app/staff` (сотрудники, роли, список терминалов) на `TenantDatabase` + RLS, правила
ADR-0018 — в сервисах, версия прав и сессии — через существующие `PermissionsVersionService` и
`SessionStore`; `POST /sessions/current/confirmation` в модуле `auth`. `apps/web`: маршруты в
`REAL_API_ROUTES`, фича `features/confirm-password` (`withFreshAuth`), действие «Задать PIN».

**Tech Stack:** NestJS 11, Kysely + pg, node-pg-migrate (SQL, только Up), Next.js static export,
TanStack Query, React Hook Form + zod, use-intl, `libs/ui`.

**Spec:** `docs/superpowers/specs/2026-10-06-staff-design.md` (утверждена архитектором 2026-10-07,
вместе с дополнениями ADR-0008 от 2026-10-06 и ADR-0013, п. 6 поправки 2026-10-05).

## Global Constraints

- Новые автотесты не пишутся до MVP (решение 2026-10-05); существующие наборы — зелёные, тесты под
  изменённые коды и поля правятся.
- Ни одной новой библиотеки; стек — CLAUDE.md «Fixed technology stack».
- Модуль `staff` — только `TenantDatabase` (`tenantTransaction`); не регистрируется при
  `STORE_MODE=offline` (`ConditionalModule.registerWhen`).
- Все мутации `staff` — `@RequireFreshAuth()`; права — как в таблице раздела 4 спецификации.
- Коды ошибок — раздел 8 спецификации, ровно эти: 400 `validation_failed`; 403
  `permission_escalation`, `store_not_in_scope`, `own_assignment`, `fresh_auth_required`,
  `password_session_required`; 404 `not_found`; 409 `last_owner`, `system_role`, `role_name_taken`,
  `login_taken`, `phone_taken`, `email_taken`; 422 `password_policy`, `pin_length`, `pin_trivial`,
  `invalid_current_password`; 429 `login_locked`.
- Аудит (та же транзакция): `employee.created`, `employee.updated`, `employee.assignment-changed`,
  `employee.password-reset`, `employee.pin-set`, `employee.blocked`, `employee.unblocked`,
  `role.created`, `role.updated`, `auth.reconfirmed`, `auth.reconfirm-failed` — без паролей и PIN.
- Названия ролей по умолчанию: «Заведующий точкой» / «Мудири нуқта», «Фармацевт-кассир» /
  «Фармасевт-хазинадор», «Бухгалтер» / «Муҳосиб»; права — `roleTemplates.manager / cashier /
  accountant`; `template_key` пустой.
- Ограничения полей: ФИО 1–200; название роли 1–60, уникально в сети без учёта регистра; логин,
  телефон (E.164), e-mail — `normalizeIdentifier`; пароль — `passwordProblems`; PIN — `checkPin` с
  `tenant_settings.pin_min_length`.
- Тексты web — RU и TJ (локаль `tg`); идентификаторы и комментарии — английские; Conventional
  Commits; GPG подписывает pinentry; перед PR пользователь запускает `npm run check`.

## Review Focus

Тестов нет — пункты проверяются живой проверкой задачи-владельца и финальным ревью:

1. Заведующий с охватом-списком назначает роль с правом, которого у него нет (например,
   `finance:view-cost`), или точку вне своего охвата → 403, и ничего не записано (Задача 4, curl).
2. Последний активный владелец: блокировка или перевод на другую роль → 409 `last_owner`; при двух
   владельцах — разрешено (Задача 4, curl).
3. Смена прав роли → у всех её сотрудников растёт `permissions_version`, следующий запрос их сессий
   видит новые права; блокировка → сессии 401 (Задача 4, curl).
4. Подтверждение паролем: PIN-сессия → 403 `password_session_required`; неверный пароль по лимиту →
   429; верный → `authenticatedAt` обновлён, действие с `@RequireFreshAuth` проходит (Задача 3, curl).
5. Web: окно «Подтвердите пароль» повторяет исходное действие ровно один раз; закрытие окна не
   показывает ошибку и ничего не отправляет (Задача 5, живая проверка + чтение кода).
