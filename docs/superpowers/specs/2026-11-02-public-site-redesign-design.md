# Редизайн публичного сайта: «смелый цветной» с анимацией

- **Дата:** 2026-11-02
- **Статус:** на утверждении у архитектора
- **Затрагивает:** `apps/site` (внешний вид, анимация, тексты главной), `package.json` (зависимость `motion` у сайта),
  `docs/architecture` (ADR-0024, stack.md, CLAUDE.md). Не затрагивает: API, админку, web, `libs/ui` (кит не меняется)
- **Требует ADR:** да, ADR-0024 «Анимация публичного сайта — библиотека `motion`» (proposed). Код с `motion` — после
  `accepted`

## 1. Зачем

Сайт части 3 работает, но выглядит как экран приложения: он собран из кита админки, все блоки одного вида
(заголовок, абзац, сетка карточек), один синий на белом, анимации нет. Пользователь (2026-11-02): «выглядит очень
простым», «нужно как премиум сайт», «не вижу анимации». Выбранное направление — **«Смелый цветной»**: глубокий
изумруд, крупная типографика, цветные блоки. Анимация — библиотекой `motion` (оформляется ADR-0024).

## 2. Цели, не-цели, анти-цели

**Цели**
1. С первого экрана сайт выглядит как продукт уровня Linear/Stripe: крупный шрифт, сильный цвет, настоящие экраны
   продукта, продуманные отступы.
2. Страница двигается осмысленно: вход первого экрана, появление секций при прокрутке, параллакс экранов продукта,
   закреплённая секция «Как подключиться», пружинные кнопки.
3. Все страницы сайта (главная, тарифы, блог, статья, оферта, политика, заявка, 404, ошибка) в одной теме.
4. SEO, ISR, адреса, тексты документов и форма заявки работают как сейчас.

**Не-цели**
- Новая структура сайта и новые страницы; новые данные в API (реквизиты, отзывы, кейсы).
- Изменение кита `libs/ui`, приложений web и admin.
- Светлая тема сайта (решение в 4.1).

**Анти-цели**
- «ИИ-шаблон»: фиолетовые градиенты, свечение, три одинаковые карточки, «Stage 1 / Stage 2», длинные тире, ярлычки над
  каждой секцией, выдуманные цифры и отзывы.
- Сайт обещает то, чего продукт не умеет (1С, фискализация, офлайн-точки как готовый продукт) — как в части 3.
- Анимация ради анимации, тормоза на телефоне, движение при `prefers-reduced-motion: reduce`.

## 3. Ограничения

- Стек сайта (CLAUDE.md, ADR-0023): Next.js с серверной отрисовкой, Tailwind v4 на токенах `--ph-*`, FSD, use-intl.
  Новая библиотека одна — `motion` 14.4.0 (ADR-0024). Шрифты, иконки и картинки — без новых пакетов.
- Анимированные компоненты — клиентские «листья»; страницы остаются серверными (ISR 60 с, готовый HTML для поисковиков).
- Токены: значения цветов — только в токенах. Палитра сайта — свои примитивы и переопределение семантических
  `--ph-color-*` в области сайта; `libs/ui` не меняется.
- Доступность: WCAG AA для текста и кнопок, фокус виден, `prefers-reduced-motion` выключает движение.
- Производительность: LCP < 2,5 с, CLS < 0,1; клиентский JS главной — до 45 КБ gzip сверх нынешнего.

## 4. Решения автора (утверждение документа — утверждение решений)

### 4.1 Тема и палитра

**Одна тёмная тема на весь сайт** (бренд-тема, без переключения светлая/тёмная): тёмный изумруд — характерный цвет
сайта, светлая версия потеряла бы направление. Секции различаются оттенками одного семейства, а не сменой темы.

| Роль | Токен сайта | Значение | Где |
|---|---|---|---|
| Фон страницы | `--ph-emerald-975` | `#04211B` | body |
| Поверхность | `--ph-emerald-950` | `#06302A` | плитки, карточки |
| Поверхность выше | `--ph-emerald-900` | `#0A3F37` | шапка при прокрутке, форма |
| Цветной блок | `--ph-emerald-700` | `#0F6E56` | блок «Тарифы», финальный призыв |
| Граница | `--ph-emerald-800` | `#11524A` | линии, рамки |
| Текст | `--ph-mint-50` | `#ECF7F2` | основной текст |
| Текст вторичный | `--ph-mint-300` | `#9CC7B8` | подписи, пояснения (AA на фонах 975–900; на цветном блоке 700 — только основной текст) |
| Акцент | `--ph-mint-400` | `#5DCAA5` | главная кнопка (текст `--ph-emerald-975`), ссылки, отметки |
| Акцент наведение | `--ph-mint-300` | `#7FD9BA` | |

- Один акцент — мята. Других цветов на странице нет (кроме статусов формы: ошибка — `--ph-color-danger` кита на тёмном
  фоне, проверить контраст).
- Цвета задаются в `apps/site/src/app/styles/site-theme.css`: примитивы `--ph-emerald-*`, `--ph-mint-*` и
  переопределение семантических `--ph-color-*` на `<html data-theme="site">`. Компоненты кита (кнопки, поля формы,
  иконки) получают палитру сайта без изменения кита.
- Чистого чёрного и чистого белого нет.

### 4.2 Типографика

- Шрифт прежний — TT Norms Pro (self-hosted из `libs/ui`, Regular, Medium, Bold). Новых шрифтов нет.
- Заголовок первого экрана — Bold, 56/60 px на десктопе (до 2 строк), 36/40 px на телефоне, `tracking-tight`.
- Заголовки секций — Bold 40/44 px; текст — Regular 18/28 px, ширина до 60 знаков.
- Акцент в заголовке — тем же шрифтом, цветом мяты (не курсивом и не другим шрифтом).
- **Ни одного длинного тире** в текстах сайта (сейчас их 17 в каждом словаре): переписать через точку, двоеточие или
  запятую.

### 4.3 Форма и материалы

- Радиусы: плитки и экраны продукта — 24 px, кнопки — полностью скруглённые, поля формы — 12 px. Других радиусов нет.
- Тени — только у экранов продукта: мягкая, тонированная в цвет фона (`rgb(1 20 16 / 0.5)`), без чёрных теней и
  свечения.
- Линии — 1 px `--ph-emerald-800`.
- Иконки — из закрытого набора `libs/ui` (новые глифы добавляются туда же, если нужны).

### 4.4 Картинки

Только настоящие экраны продукта на синтетических данных моков `apps/web` (как `pos.png` части 3): касса, остатки по
партиям со сроками, приход, отчёт продаж, перемещения, кабинет владельца (главная). Снимаются Playwright в 2× (для
резкости), сохраняются в `apps/site/public/images/` как WebP, ширина до 1600 px, каждый ≤ 200 КБ. Без стоковых фото,
без нарисованных «скриншотов» из `div` и без декоративных SVG.

### 4.5 Главная — секции сверху вниз

Каждая секция — своя раскладка; ярлычок над заголовком — не больше одного на три секции.

1. **Шапка.** Прозрачная над первым экраном. После прокрутки на 24 px получает фон `--ph-emerald-900` с размытием и
   линию снизу (`useScroll`, без обработчика прокрутки). Высота 72 px, одна строка: название или логотип, «Возможности»,
   «Тарифы», «Блог», «Контакты», RU/TJ, «Войти», кнопка «Оставить заявку». Меньше 1024 px — меню.
2. **Первый экран — несимметричный.** Слева: заголовок (до 2 строк), подзаголовок (до 20 слов), кнопки «Оставить
   заявку» и «Тарифы». Справа: три наложенных экрана продукта (касса впереди, партии и отчёт за ней, со сдвигом и
   лёгким наклоном). Вход: текст поднимается и проявляется по строкам, экраны выезжают по очереди (пружина). При
   прокрутке экраны расходятся с разной скоростью (параллакс, только ≥ 1024 px). Высота — не больше экрана
   (`min-h-[100dvh]` с ограничением), кнопки видны без прокрутки.
3. **Бегущая строка возможностей** (единственная на сайте): «Касса», «Партии и сроки», «Закупки», «Перемещения»,
   «Инвентаризация», «Отчёты и Excel», «Роли и права», «Загрузка каталога». Медленная, останавливается при наведении;
   при `reduce` — неподвижная строка с переносом.
4. **«Для кого» — закреплённый заголовок.** Слева закреплён крупный заголовок, справа прокручиваются четыре боли
   (сроки и партии, недостачи, несколько точек, перебои связи), каждая проявляется при входе.
5. **Возможности — плитки разного размера** (ровно 6 плиток, без пустых): касса (большая, с экраном), партии и сроки
   (с экраном), закупки, цены и скидки, перемещения (с экраном), отчёты и Excel. Минимум три плитки с экраном продукта
   или цветным фоном. Плитки появляются каскадом; при наведении экран внутри плитки чуть приподнимается.
6. **Как подключиться — закреплённая секция с прогрессом.** Пять шагов (заявка, звонок оператора, сеть и код
   активации, загрузка каталога, первая продажа) идут по горизонтальной линии; линия заполняется по мере прокрутки
   (`useScroll` + `scaleX`), текущий шаг подсвечивается. Без «Шаг 1 / Шаг 2»: глагол и есть заголовок шага. Меньше
   1024 px — вертикальный список с той же линией.
7. **Тарифы — цветной блок** (`--ph-emerald-700`, единственный на странице кроме финального призыва): крупная цена
   точки в месяц (из API, `formatMoney`), строка «НДС N % сверху», ссылка на `/tariffs`. Цифра проявляется при входе.
8. **Безопасность — две колонки**: слева заголовок и короткий текст, справа пять утверждений с иконками (только
   верные, как в части 3).
9. **Вопросы и ответы — аккордеон** на `<details>` с плавным раскрытием высоты.
10. **Финальный призыв** — во всю ширину, `--ph-emerald-700`, крупный заголовок и кнопка «Оставить заявку»
    (та же надпись, что в шапке и первом экране — один ярлык на одно действие).
11. **Подвал** — четыре колонки (бренд, разделы, документы, контакты) на `--ph-emerald-975`, без декоративных строк.

### 4.6 Остальные страницы

- **Тарифы** — крупная цена с НДС, разовые услуги плитками (не таблицей), призыв к заявке.
- **Блог** — карточки статей с обложкой (или цветной плиткой без обложки), появление каскадом; статья — колонка
  текста 68 знаков, обложка во всю ширину колонки, `SiteMarkdown` в цветах темы.
- **Оферта, политика** — спокойная колонка текста, без анимации кроме входа заголовка.
- **Заявка** — форма на поверхности `--ph-emerald-900`, слева короткий текст «что будет после заявки» (три пункта),
  справа форма; экран «Заявка принята» — с мягким входом. Поведение формы (проверки, ловушка, ошибки) не меняется.
- **404 и ошибка** — крупная цифра, текст, кнопка на главную, в теме сайта.

### 4.7 Движение (`motion`, ADR-0024)

| Что | Как | Зачем |
|---|---|---|
| Вход первого экрана | `motion` с задержкой по порядку, пружина `stiffness 100, damping 20` | Показать главное первым |
| Появление секций и плиток | `whileInView`, `once`, `y: 24 → 0`, `opacity`, каскад 0,06 с | Ритм чтения |
| Параллакс экранов | `useScroll` + `useTransform`, ≥ 1024 px | Глубина первого экрана |
| Шапка | `useScroll` → фон и линия | Читаемость поверх контента |
| Закреплённые секции 4 и 6 | `position: sticky` + `useScroll` | Рассказ по шагам |
| Кнопки | `whileHover` / `whileTap` (`scale 0.98`) | Отклик на действие |
| Бегущая строка | CSS `@keyframes` (без JS) | Широта возможностей |

- Компоненты движения — общий слой `apps/site/src/shared/ui/motion/` (`Reveal`, `RevealGroup`, `Parallax`,
  `PressableButton`; «магнитных» кнопок нет), все с `'use client'` и `useReducedMotion()`.
- При `reduce`: всё видно сразу, нет параллакса, закрепления и бегущей строки (статичная строка).
- Анимируются только `transform` и `opacity`. `window.addEventListener('scroll')` запрещён.

### 4.8 Тексты

- Тексты главной переписываются под новую структуру (короче: заголовок секции до 8 слов, абзац до 25 слов), смысл и
  правдивость — как в части 3 (касса без связи «до суток или 500 операций», цена «одна по прайсу», безопасность без
  общих отрицаний).
- Таджикские тексты — перевод, на ревью носителя.

## 5. Рассмотренные подходы

| | Подход | Плюсы | Минусы | Итог |
|---|---|---|---|---|
| 1 | **Тема сайта поверх кита + свои секции + `motion`** | Кит не меняется, компоненты формы и кнопки получают палитру через токены; движение — проверенной библиотекой | Новая зависимость (ADR-0024) | **Выбран** |
| 2 | Только CSS-анимация | Без зависимостей | Нет пружин и надёжного закрепления, Firefox без scroll-timeline | Отклонён пользователем |
| 3 | Отдельный набор UI для сайта (shadcn и т. п.) | Готовые блоки | Второй кит, новые зависимости, расходится с ADR-0007 | Отброшен |

## 6. Проверка готовности

- Главная и все страницы на стенде test: десктоп 1440 и телефон 375, без горизонтальной прокрутки, первый экран
  целиком виден, анимация работает, при `prefers-reduced-motion: reduce` всё статично.
- Lighthouse (production-сборка): Performance ≥ 90 на десктопе, LCP < 2,5 с, CLS < 0,1, Accessibility ≥ 95.
- Контраст всех текстов и кнопок — AA (проверка axe).
- Ни одного `—` в словарях и разметке сайта.
- SEO не изменилось: canonical, hreflang, sitemap, robots, Open Graph — как в части 3.

## 7. Оставлено исполнителю

Точная композиция экранов на первом экране и в плитках, тексты RU (с последующим TJ), кривые и длительности в
пределах 4.7, имена компонентов, разбиение на задачи.
