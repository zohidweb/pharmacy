# C4 — Context: Сервис уведомлений клиентов

```mermaid
C4Context
    title Контекст системы — Сервис уведомлений клиентов

    Person(client, "Клиент банка", "Получает СМС/push о движениях по своему счёту")
    Person(operator, "Оператор банка", "Настраивает шаблоны уведомлений, следит за доставкой")

    System(notify, "Сервис уведомлений клиентов", "Формирует и отправляет клиентам уведомления о движениях по счёту")

    System_Ext(abs, "АБС", "Источник событий по движению средств")
    System_Ext(smsgw, "СМС-шлюз", "Внешний провайдер доставки СМС")

    Rel(abs, notify, "События по счёту (списание/зачисление/отказ)", "REST/JSON")
    Rel(operator, notify, "Управление шаблонами, мониторинг доставки", "HTTPS")
    Rel(notify, smsgw, "Отправка СМС", "REST/JSON")
    Rel(notify, client, "СМС / push-уведомление")
```

## Легенда

- **Клиент банка** — получатель уведомлений; сам с системой не взаимодействует, только получает СМС/push.
- **Оператор банка** — единственный пользователь веб-интерфейса сервиса: настраивает шаблоны текстов и наблюдает за статусами доставки.
- **АБС** — внешняя система-источник; присылает события по счёту через утверждённый API-слой, прямого доступа к её БД нет.
- **СМС-шлюз** — внешний провайдер связи; получает только номер телефона и текст уведомления, доступ — через DMZ-прокси (см. deployment.md).
- Все внешние системы совпадают со списком в stack.md, раздел «4. Интеграции».
