```mermaid

    title Контейнеры — Сервис уведомлений клиентов

    Person(operator, "Оператор банка", "Настраивает шаблоны, следит за доставкой")
    System_Ext(abs, "АБС", "Источник событий по движению средств")
    System_Ext(smsgw, "СМС-шлюз", "Внешний провайдер доставки СМС")

    System_Boundary(notify, "Сервис уведомлений клиентов") {
        Container(spa, "Angular SPA", "Angular, TypeScript", "Веб-интерфейс оператора: шаблоны, мониторинг доставки")
        Container(api, "API уведомлений", "C#, .NET, REST", "Приём событий от АБС, REST-эндпоинты для SPA, постановка задач в очередь отправки")
        ContainerQueue(mq, "RabbitMQ", "RabbitMQ", "Очередь критичных уведомлений (отказ операции); исключение из радара, см. ADR-0003")
        Container(worker, "Воркер отправки", "C#, .NET", "Формирует текст и отправляет уведомления через СМС-шлюз")
        ContainerDb(db, "PostgreSQL", "PostgreSQL", "Клиенты, шаблоны, история уведомлений")
        ContainerDb(cache, "Redis", "Redis", "Очередь задач на отправку, кэш шаблонов и статусов доставки")
    }

    Rel(operator, spa, "Работает через браузер", "HTTPS")
    Rel(spa, api, "Запросы админ-интерфейса", "REST/JSON")
    Rel(abs, api, "События по счёту", "REST/JSON")
    Rel(api, db, "Чтение/запись", "SQL")
    Rel(api, cache, "Постановка задач на отправку", "Redis protocol")
    Rel(api, mq, "Постановка критичных уведомлений (отказ операции)", "AMQP")
    Rel(worker, mq, "Выборка критичных уведомлений", "AMQP")
    Rel(worker, cache, "Выборка задач", "Redis protocol")
    Rel(worker, db, "Чтение шаблонов, запись статуса доставки", "SQL")
    Rel(worker, smsgw, "Отправка СМС", "REST/JSON")
```

## Легенда

- **Angular SPA** — единственный пользовательский интерфейс сервиса, доступен только оператору банка.
- **API уведомлений** — точка входа для событий АБС и для SPA; сам не отправляет уведомления, а ставит задачи в очередь (Redis).
- **Воркер отправки** — отдельный процесс, читает очередь задач и вызывает СМС-шлюз; разделён с API по стилю «модульный монолит» (см. ADR-0002).
- **RabbitMQ** — отдельная очередь только для критичных уведомлений (отказ операции); одноразовое исключение из радара, см. ADR-0003; не расширять на другие сценарии.
- Технологии контейнеров соответствуют stack.md, раздел «3. Выбор стека», включая исключение RabbitMQ по ADR-0003; других технологий в контейнерах нет.
